# Grand Theft Auto VI Start

Двуязычный статический справочник, GitHub Pages. Обновление 18.11.2026.

## Языки и Telegram

Русская версия находится в корне, английская — в `en/`. Каждая из 15 страниц содержит переключатель на соответствующую страницу другого языка и ссылку https://t.me/kklenews. Общие стили, изображения, карта и список IANA-поясов используются без дублирования; английские тексты, интерфейсные скрипты и подписи данных хранятся в `en/`. При изменении функций обновляйте обе языковые версии. Ключи локального прогресса общие. Пользовательские заметки и названия целей не переводятся.

Аналитика посещений пока не подключена по просьбе владельца. Счётчиков, трекинг-скриптов и публичного раздела статистики нет. Закрытую статистику позже следует подключить через авторизованную панель сервиса; секреты нельзя размещать в публичном репозитории.

## Данные и разрешение

Пользователь сообщил о разрешении владельца GTABase и предоставил скриншот письма с разрешением использовать данные для изменённого продукта. Личные данные и переписка в репозиторий не включены. Сайт не является официальным продуктом Rockstar или GTABase.

Каталоги: https://www.gtabase.com/gta-6/vehicles/ (317), https://www.gtabase.com/gta-6/weapons/ (51). Данные перенесены с отображаемых карточек, без доступа к приватным API. 368 изображений сохранены локально в assets. Некоторые изображения относятся к прошлым GTA; это отмечено в карточках. Рабочие названия не выдаются за подтверждённые игровые. Цены, скорость и урон не выдуманы.

Карта: https://www.gtabase.com/gta-6/map/, 192 маркера, 29 непустых категорий. Собственный интерфейс на Leaflet; оригинальный виджет GTABase не перенесён. Местные фотографии скопированы в assets/places. 593 тайла yanis17 (уровни 0–3) сохранены локально в 41 JSON-пакете, внешнего сервера карта не требует. Уровни 4–6 увеличивают третий уровень без добавления детализации. Авторы тайлов: gtadb.org и участники, CC BY 4.0; атрибуция и ссылка на лицензию сохранены в карте. Категории переведены, оригинальные описания мест оставлены отдельно; карта сообщества может содержать предварительные координаты.

Миссии: https://www.gtabase.com/missions/gta-6/prologue — опубликована одна карточка; целей и золотых условий ещё нет. Проверенное полное прохождение отсутствует.

Данные каталога: catalog-data.js. Данные карты: map-data.js. Прогресс локальный, ключ start-world-state. Экспорт/импорт объединяет прогресс; личные схемы прежней версии доступны в map-custom.html и не удалены.

## Проверка и обновление

Никакой автоматической синхронизации нет. Данные обновляются публикацией нового снимка после проверки. Старые страницы регионов и целей сохранены. IANA zones: regions.js. Официальные изображения оформления: Rockstar Games, https://www.rockstargames.com/VI/media/screenshots.
